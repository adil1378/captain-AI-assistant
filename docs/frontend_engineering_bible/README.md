### Development Rules & Scope Boundaries
1. Strictly follow the 8-Step Workflow: Specification $\rightarrow$ Review & Approval $\rightarrow$ Implementation $\rightarrow$ Synchronization $\rightarrow$ Testing $\rightarrow$ Verification $\rightarrow$ Documentation Update $\rightarrow$ Completion Report.
2. Only one Part active at a time.
3. No backend, AI, agent, memory, RAG, perception, or API modifications during Frontend Engineering Bible work.
